# Quaternius — Stylized Nature MegaKit (CC0)

This experimental scenery includes 3 genuine **optimized GLB** models from Quaternius' **Stylized Nature MegaKit**: CommonTree 1 (`tree1.glb`), CommonTree 4 (`tree3.glb`) and Bush_Common (`bush.glb`).

**Original creator and license:** Quaternius — CC0 1.0 Universal.
https://quaternius.com/packs/stylizednaturemegakit.html
https://creativecommons.org/publicdomain/zero/1.0/

**Optimized GLB mirror / provenance:** https://github.com/anshaneja5/skyline-run/tree/main/public/assets/models — original models credited to Quaternius in that project's `CREDITS.md`; converted for web with glTF-Transform and WebP textures. The original free pack is available at the author's site.

In the V5 arena they are added only to **the outside ring**, behind the grandstands. No physics, player input, hero rigs, talents, damage, XP, or database writes. The three new models are instantiated by `loadMedievalArchitecture` using shared geometry and materials; counts decrease automatically in low quality. The existing procedural citadel remains as the fallback if models fail to load.
