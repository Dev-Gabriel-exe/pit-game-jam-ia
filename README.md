# PIT Game Jam IA

Projeto exclusivo da oficina PIT Game Jam IA, separado do site pessoal.

Portal público (após ativação do GitHub Pages): https://dev-gabriel-exe.github.io/pit-game-jam-ia/

A oficina utiliza cadernos HTML independentes, biblioteca de recursos e mapa de missões. O progresso é mantido no navegador do aluno, salvo exportação/importação.

Os arquivos são publicados a partir da raiz do repositório por GitHub Actions.
